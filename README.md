# 平江图地名库

南宋《平江图》碑刻（苏州现存最早的城市地图）的**可标注、可协作、可检索**的网页版。

原碑刻有 600 余处地名，字迹细密、漫损严重。本项目把碑上可辨认的文字块逐个检测出来，做成可点选的点位，由人判读命名，任何人可提交修订、由维护者审核通过后公开。

线上版：<https://pingjiang-map.app.workbuddy.host/?sharecode=OEGGL35LB5>
仓库：<https://github.com/JoeFirmament/pingjiangtu>

功能：

- 滚轮 / 双指缩放，拖拽平移；点位缩到全图仍可见（6px 朱砂小点）
- 标注文字**脱离缩放图层**，按屏幕坐标排版，任何倍率都是矢量清晰
- 旗标式标注：朱砂实底 + 纸色字，方位（上/下/左/右）与排布（横/竖）可逐点调整
- 搜索：繁简兼容、空格分词、按类型筛选
- 判读工作台：逐点命名、分类、写注记；导出 / 导入 JSON 备份
- 协作：任何人不登录可提交修订，维护者审核后进入公开数据

## 构建

```bash
cd 地点索引
python3 build.py
```

产物两份：

- `../平江图在线/index.html` —— 线上版。中图 2207px 内嵌保证首屏必现，`map/full.jpg` 外链按需升级
- `../平江图高清/平江图_地点数据库.html` —— 单文件离线版。底图整张内嵌，可直接拷给别人双击打开

只依赖 Python 标准库。

## 底图

640 年前后的碑刻原石藏在苏州文庙，拓片扫描件来自公开渠道（苏州历史文化网 300dpi 版本）。
扫描件整体发灰（黑场被抬到 RGB 72），因此以锐化版为母版做了双色调映射：墨 `#221f1a`、纸 `#fbfaf5`，
再导出三档 JPEG。像素尺寸与标注坐标严格对齐，重制不影响坐标。

碑刻拓片本身属公有领域；本仓库的代码与判读数据可自由取用。

## 版本

`主.次.修订`：主 = 数据结构或统计口径变化，次 = 功能，修订 = 样式与文案修正。
发版流程：改 `VERSION` → 更新 `CHANGELOG.md` → `python3 build.py` → commit → 打标签 → 发布。
